# Независимые приёмочные тесты: ‹название витка›

> Готовит независимый проверяющий по согласованным требованиям до этапа 5, без кода кандидата
> и объяснений разработчика. Канонический источник — SDLC.md. Это манифест: исполняемые тесты
> и результаты хранит отдельный исполнитель, не автор реализации.

- **Риск и основание:** ‹низкий / обычный / высокий — основание из plan.md›
- **Контракт:** ‹ревизия intent.md; согласованные claims и ограничения›
- **Проверяющий:** ‹модель, квантизация, движок, шаблон, контекст; ссылка на квалификацию роли›
- **Набор:** ‹revision и SHA-256 каждого файла тестов/фикстур; список файлов›
- **Место хранения и защита:** ‹пути, владелец; sandbox/ACL исполнителя; разработчику только чтение›
- **Среда и запуск:** ‹зависимости, конфигурация и именованная команда исполнителя›
- **Зафиксировано до реализации:** ‹время и базовая ревизия кода›

Хеш этого манифеста сохраняет исполнитель снаружи, в записи фиксации набора; документ не
содержит собственного хеша. После фиксации он не дополняется результатами кандидата.

| Claim | Вход/фикстура | Ожидаемый результат и побочные эффекты | Тест/проверка |
|---|---|---|---|
| claim-1 | ‹данные› | ‹наблюдаемое поведение› | ‹test-id› |

## Исходный прогон и чувствительность

- **Baseline:** ‹ревизия, команда, фактический результат и ссылка исполнителя; для нового поведения допустимо ожидаемое падение›
- **Контроль ошибки:** ‹старый дефект / посев / property / обоснованная процедура; что тест обнаруживает›
- **Известные ограничения:** ‹что не проверяется› / нет

## Изменения и решения

Правка ошибочного теста — отдельное ревью; изменение ожидания — решение человека и новая
ревизия контракта. Разработчик не меняет этот набор, его манифест и свидетельства. Новый хеш
обнуляет результаты старого набора. Отсутствие sandbox не скрывается за обещанием промпта.

- **Неприменимость:** ‹причина, имя и дата решения человека› / нет — гейт применим

## Результаты кандидата

Исполнитель пишет их отдельно в артефакты попытки и verification-report: ревизия кода,
внешний хеш этого манифеста, хеши тестов/фикстур, среда, команда и фактический исход.
Результат не изменяет зафиксированный набор и его манифест.
