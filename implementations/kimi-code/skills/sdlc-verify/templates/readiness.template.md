### Критерии, которые Runner обязан проверить

_Прогон 1 проверяет семь критериев:_

1. Обязательный набор гейтов собран.
2. «Что делаем» и «Чего не делаем» заполнены.
3. Приёмка соответствует минимуму выбранного контура.
4. У каждого пункта есть процедура и критерий проверки.
5. Инварианты названы или явно отсутствуют.
6. Для блокирующих вопросов записаны ответы человека.
7. В задаче нет незаполненных полей.

_Прогон 2 проверяет пять критериев:_

1. Блокирующие вопросы закрыты.
2. Новые незаполненные поля не появились.
3. Разведка заполнила «Что придётся тронуть».
4. Если критерии изменены, примеры пересчитаны.
5. После правок сохранены процедуры проверки и минимальное число пунктов и `[edge]`.

_В каждой строке **Проверки** укажи статус и наблюдаемое свидетельство.
Отметка вопроса не заменяет ответ человека. Учитывай только непустой ответ в `clarification-report.md`._
