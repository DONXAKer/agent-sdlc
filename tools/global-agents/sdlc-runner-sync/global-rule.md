## Согласование методологии Agent-SDLC с Runner

После правок методологии Agent-SDLC передай проверку согласованности глобальному агенту `sdlc-runner-sync`.
Это относится к SDLC.md, общим шаблонам, гейтам, контрактам и инструкциям этапов.
Передай корень методологии, фактический diff и область задачи. Дождись результата перед завершением работы.
Агент актуализирует соседний Agent-SDLC-Runner либо создаёт проверяемые задачи в https://github.com/DONXAKer/Agent-SDLC-Runner.
Правки без влияния на Runner допускают исход «не влияет» с проверяемым объяснением.
Если роль ещё не загружена текущей сессией, используй агента `default` с инструкциями из `~/.codex/agents/sdlc-runner-sync.toml`.
Не создавай коммиты, push и релизы без отдельного запроса. Сообщи файлы, проверки и ссылки на созданные задачи.
