# Сквозной рублёвый профиль — виток целиком без облачных моделей

**Состав:** этапы 1–5 и handoff — `polza:ministral-8b` (~5 ГБ, formFill на 1–4),
этап 6 — `polza:ministral-14b` (~9 ГБ, лимит 60 ходов). Правило рецензента 40 > 30
соблюдено без единой облачной модели. **Задача:** та же `parcel-price` / `oversize`.

**Итог: методология живёт целиком на ≤16 ГБ до настоящего вердикта.** Все артефакты
заполнены, вердикт этапа 6 — `passed:false, retry` **по делу**: сэмпл chunk повесил
надбавку на габаритные отправления, тесты проекта красные, рецензент нашёл регрессию.
Красный вердикт, поймавший настоящие баги, — это работающая методология, а не провал.

## Цена пути

До успешного витка — 11 попыток; 7 остановок были реальными дефектами конструкции
раннера (не моделей), все починены: ретрай 5xx, задача в промпт intent, поле-образец
таблицы, извлечение таблиц из прозы, секция-контекст с легендой, второй проход по полям,
защита полей решений человека. Детали — журнал раннера, запись r10.

**Следующий замер:** серия `--repeat 3` этого профиля (качество сэмпла и human-кейсы
с настоящими ответами человека).
