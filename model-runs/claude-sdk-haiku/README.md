## Роль рецензента (`claude-sdk:haiku-reviewer`, rank 61) — обход правила, этап 6 (2026-09-28)

Отдельная запись `config/models.json` (rank 61) — намеренный обход правила «рецензент строго
сильнее исполнителя»: сентябрьский замер (`bench/results/axes-haiku-*`) показал, что `haiku`
(rank 40) ловит оба осевых посева свободным ходом, а `sonnet` (rank 70) — ни одного. Первый
ЧЕСТНЫЙ замер находимости после фикса «посев физически доходит до рецензента на
`--from-snapshot`» (`Agent-SDLC-Runner/docs/model-runs.md`, 2026-09-28; до фикса рецензент на
снимках читал патч БЕЗ посева — все прежние числа по этим классам измеряли слепоту стенда, не
модели), снимок `oversize-axes2` (chunk — `claude-sdk:sonnet`, ранг 70 — то есть числа ниже
меряют силу рецензента при СИЛЬНОМ исполнителе, а не типичный сценарий «локальный chunk +
локальный verify»; прямого сравнения на коде слабой модели в этой серии нет):

| Посев | Исход | Стоимость |
|---|---|---|
| `axis-config-blind` (ось «настройки» — значение из окружения без умолчания) | ✅ поймано, вердикт `escalate` (2 подтверждённых расхождения из ревью) | $0.61 |
| `axis-secret-in-log` (ось «безопасность» — данные заказа в логе) | ✅ поймано, вердикт `retry` (claim-7 опровергнут) | $0.71 |
| `none` (контроль) | сработало — но найденное не выдумка: `test/oversize.test.ts:59` реально использует `weightG=900` вместо требуемых заданием `weightG=300` (claim-7) — настоящий дефект снимка, не галлюцинация и не эффект посева | $0.55 |

**Вердикт: годится рецензентом на класс осевых посевов — 2 из 2 с первого раза.** Подтверждает
сентябрьский вывод «модель, не только ранг». n=1 на класс — не серия; ≥3 не снято.
Побочный эффект замера — контроль `none` на снимке `oversize-axes2` недостоверен, пока
`test/oversize.test.ts:59` не поправлен (баг фикстуры `bench/fixture/`, не модели и не
раннера) — щуп честности стенда (`probeNoSeed`) не отличает настоящую находку от выдумки на
контрольном прогоне, что тоже стоит держать в голове при чтении будущих `none`-контролей.
