# Передача контекста: ‹название витка›

> Создай handoff на этапе 7 и при любом обрыве витка. Передай контекст следующей сессии.
> Для следующего витка добавь новую секцию. Старую секцию не перезаписывай. Правила: SDLC.md → этап 7.

## Виток ‹K› — ‹дата›

_Секции витков располагай в порядке времени. Инструменты читают последнюю секцию.
Для нового витка добавь секцию с новым номером._

- **Задача:** ‹id или название — то же на всех витках этой задачи›
- **Предыдущая передача по этой задаче:** ‹ссылка или файл› / нет — это первый виток
- **Приёмка:** принял ‹имя› · ‹дата› / **не принималась — обрыв: ‹почему›**

## Готовность

_Переноси статусы из отчёта без изменений, включая `⏭`. Пропущенный гейт нельзя обозначать как успешный._

- Пункты в `❌`: ‹id› / ни один · Пункты в `⚠`: ‹id› / ни один / н/п — приёмка не запускалась
- **Пункты `[manual]` — открытая ручная проверка** (не проверялись этим этапом по построению,
  не роняли `passed`): ‹id — что именно проверить и как› / ни одного

| Гейт | Статус |
|---|---|
| ‹гейт› | ‹✅/❌/⏭› |

Если приёмка не запускалась, удали таблицу. Оставь «н/п — приёмка не запускалась»._

- Закрыто вручную вместо гейта из долга: ‹ссылка на строку «Долга» в наборе› / н/п

## Наблюдения витка

_Сохраняй наблюдения, а не цели или квоты. Возвраты бери из журнала chunk, дефекты — из блоков ниже.
Статусы гейтов повторно не копируй: они находятся в «Готовности»._

- Возвратов на этом chunk'е: ‹K−1 из журнала chunk'а› _(0 = приёмка с первой попытки)_
- Пункты, закрытые не тестом, а diff'ом: ‹id› / ни один
- Записи о дефектах на этом витке: ‹имена из блоков ниже› / ни одной

## Запись о проскочившем дефекте

_Создай запись, если дефект прошёл гейты или ревью обнаружило поведение без пункта приёмки.
Проверь все отчёты витка. Для каждого дефекта создай отдельный блок._

_Если дефектов нет, оставь один блок: «Имя» = «нет», остальные поля = `н/п`.
Только в этом случае «Действие» и «Кто утвердил» допускают `н/п`.
Для реального дефекта заполни все поля. Без действия и имени утвердившего запись не завершена._
