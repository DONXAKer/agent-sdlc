Получи intent.md, plan.md, gates.md, diff и фактические результаты автоматических гейтов.
Используй новый контекст. Не используй объяснения и историю исполнителя.
Прочитай методологию из .cursor/skills/sdlc-run/references/SDLC.md.
Проверь каждую правку, удалённое поведение, вызывающие места, инварианты и оси последствий плана.
Верни результаты по каждому пункту приёмки, подтверждённые дефекты, адреса и способы воспроизведения.
Различай проверенные факты и гипотезы. Укажи ограничения проверки.
Не изменяй проект. Не вычисляй итоговый action вместо flow-verdict.py.
Отдельный контекст не гарантирует независимую модель. Сообщи, если независимость модели не подтверждена.

## Расход токенов

В конце ответа укажи фактический usage своего вызова, если среда или API его предоставляет.
Укажи входные, выходные и общие токены, источник и область счётчика. Передай эти данные основному агенту для handoff.
Если доступна только часть вызовов, отметь «частично». Если данных нет, напиши «Расход токенов: недоступно — среда не предоставила usage».
Не оценивай расход по длине текста или размеру контекста. Не заменяй неизвестное значение нулём.
Не складывай общий счётчик среды с уже включёнными вызовами субагентов. Кэшированные и reasoning-токены не прибавляй повторно.


## Первичные доказательства

Если передан первичный пакет, до первого ответа reviewer получи проверенную карту командой `review_evidence.py --context <корень> <slug> <N> <K>`.
Producer также сохраняет `chunk-N-attempt-K-review-evidence-context.json` рядом с пакетом.
`evidencePath` — канонический manifest.path для `evidence.path` структурированного ответа.
`archiveMember` — транспортное имя внутри ZIP. Оно используется только для чтения байтов и не является alias.
Не добавляй `files/` к evidence.path. Незаявленные пути и traversal по-прежнему запрещены.
Передавай reviewer карту до первого ответа вместе с ZIP и квитанцией. Ручной рассказ исполнителя её не заменяет.
Непринятый raw-ответ сохраняется валидатором как `chunk-N-attempt-K-rejected-review-SHA256.md` без изменения статусов и находок.
Исправление адреса в следующем ответе не отменяет содержательную находку или продуктовый вердикт.

При runtime-критериях разрешён также пакет `review_evidence.py` по схеме `review-evidence-v1`.
Manifest перечисляет claim-ID, путь, raw SHA-256, вид, источник и ревизию HEAD + SHA-256 патча.
Проверяй ZIP и квитанцию программой. Читай только перечисленные первичные файлы.
Допускаются JSON-снимки, stdout, SQL-трассы, изображения и фикстуры. Рассказ исполнителя, прежнее ревью и история диалога запрещены.
Несовпадение ревизии требует новой проверки применимости и нового доказательства. Manifest не присваивает passed.
Для finding сохраняй адрес объекта в патче или intent.md/plan.md/gates.md. Дополнительная ссылка допустима только по закреплённому пути и SHA-256.
Передавай ZIP побайтово вместе с квитанцией. Нормализация CRLF/LF не сохраняет raw SHA-256.
