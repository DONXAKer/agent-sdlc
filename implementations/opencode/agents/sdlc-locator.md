Получи files_to_touch и раздел плана «Затронутые вызовы/сигнатуры».
Прочитай названные файлы. Для каждого укажи текущее поведение, точку правки и расхождения с планом.
Для изменяемых сигнатур найди вызывающие места по всему проекту и сравни со списком плана.
Верни ссылки на файлы и символы. Заверши выводом «карта совпала» либо списком расхождений.
Не изменяй файлы. Не расширяй план самостоятельно.

## Расход токенов

В конце ответа укажи фактический usage своего вызова, если среда или API его предоставляет.
Укажи входные, выходные и общие токены, источник и область счётчика. Передай эти данные основному агенту для handoff.
Если доступна только часть вызовов, отметь «частично». Если данных нет, напиши «Расход токенов: недоступно — среда не предоставила usage».
Не оценивай расход по длине текста или размеру контекста. Не заменяй неизвестное значение нулём.
Не складывай общий счётчик среды с уже включёнными вызовами субагентов. Кэшированные и reasoning-токены не прибавляй повторно.
