# Agent-SDLC для Codex

Самостоятельный интерактивный флоу из десяти навыков и четырёх ролей.
Требуются Python 3.11+, Git, авторизованный Codex с поддержкой пользовательских агентов и инструменты проекта.
Runner, Claude Code, Bash и локальный сервер моделей для установки не нужны.

Из этого каталога выполни:

```text
python install-codex.py --doctor
python install-codex.py --project /путь/к/проекту
python install-codex.py --project /путь/к/проекту --check
```

Для пользовательской установки замени `--project ...` на `--user`.
На Windows можно использовать `py -3.11`, на Linux и macOS — `python3`.
Открой новую сессию Codex в проекте. Запусти `$sdlc-run <slug> <задача>`.
Для продолжения вызови `$sdlc-run <slug>`. Этапы доступны отдельно через `$sdlc-intent`,
`$sdlc-explore`, `$sdlc-ask`, `$sdlc-plan`, `$sdlc-chunk`, `$sdlc-verify`, `$sdlc-handoff`.
Между витками доступны `$sdlc-seed` и `$sdlc-retro`.

Установщик копирует все ресурсы. Исходный клон после установки не нужен.
Отличающиеся файлы сохраняются в `.codex/sdlc-backup-*`. Удаляются только устаревшие файлы собственного манифеста.
Конфигурация Codex и чужие навыки не переписываются. Ключи и авторизация в комплект не входят.

## Границы

Это адаптация канонического Markdown-флоу. Витки Runner v2/v3 и state-first продолжай в Runner.
Отдельный агент обеспечивает разделение контекста, но не независимость модели и не отдельную песочницу.
Hooks Claude Code и технические защиты Runner здесь отсутствуют. Пропуск проверки блокирует положительный вердикт.
Коммит и push требуют явного запроса. Инструменты сборки и тестов определяются целевым проектом.

## Проверка и упаковка

Запусти `python test_package.py`. Для архива выполни `python package.py`.
Манифест содержит исходную ревизию и контрольные суммы. Проверка сопоставляет канонические ресурсы при наличии исходного репозитория.
Ручные изменения установочных копий требуют синхронизации с каноническими файлами и обновления манифеста.
Живой полный виток Codex пока не подтверждён. Проверки установки не доказывают качество выполнения этапов моделью.
