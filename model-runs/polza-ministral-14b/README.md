# `polza:ministral-14b` (Mistral Ministral 14B, ~9 ГБ Q4) — исполнитель этапа 5 и рецензент этапа 6

- **Задача:** та же фикстура `parcel-price` / `oversize` (см. README уровнем выше);
  этап 5 мерился со снимка `oversize-plan` (вход побайтово тот же, что у контроля),
  этап 6 — со снимка `oversize-chunk`.
- **Серии:** r2, r2b, r3/r3b, r4, r5 (×3), r6/r6b, r9/r9b — 2026-08-30, всё через polza.

## Что делалось по этапам

- **Этап 5 (chunk), 10+ прогонов.** Код устойчиво сильный: 5 из 10 прогонов — **9/9 скрытых
  тестов, включая 3/3 human** (ставка 90% из ответа человека дошла до кода дословно), ~2–3
  минуты и ₽2–3 за прогон. Хронический провал — закрытие этапа: модель сжигала лимит ходов
  на заполнении журнала chunk'а инструментами. Вылечено конструкцией раннера
  (автозаполнение механики + дозаполнение по полям `formFill`): в r6b оба прогона прошли
  chunk → verify целиком. Один сэмпл из ~3–7 — разрушительная перезапись (ловится гардом).
  `temperature: 0` — ухудшение (2/6+0/3), откачено.
- **Этап 6 (verify), серия r9.** При лимите 60 ходов закрывает отчёт приёмки **сама**,
  переносит статусы гейтов с **0 расхождений** с фактическим прогоном и находит настоящее
  расхождение ревью. При лимите 40 ходов не успевала — ручка решающая.

## Результат и вердикт

- **Этап 5: ✅ с ручкой `formFill`** — первый кандидат класса ≤16 ГБ, доводящий виток до
  настоящего вердикта этапа 6.
- **Этап 6: ✅ при t60** — найденный рецензент класса 8–16 ГБ (rank 40 > 30 у ministral-8b,
  правило рецензента соблюдено без opus).
- Дисперсия сэмплов высокая: единичный прогон недоказателен, мерить сериями ≥3.

## Ресурсы

- Этап 5: ~2м45с, ₽2.7, 793k входных токенов (лучший прогон r6b).
- Этап 6: ₽5.9 при 60 ходах (r9b).
