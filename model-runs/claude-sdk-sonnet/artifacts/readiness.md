**Человеческая часть** — ответы человека, не агента:

Источник: файл ответов (`human.json`, неинтерактивный прогон). На все четыре вопроса
(необходимое / единичное / однозначное / проверяемое) автоответчик вернул общий fallback:
«Ответа у меня нет: это видно из кода, прочитай его сам.» — ни одно из правил `answers.rules`
и `noise` в файле не рассчитано на оценку качества самого артефакта, только на факты
тарифной политики. Специфических возражений от человека не поступило.

Поскольку живого суждения по этим четырём пунктам файл ответов не даёт, ниже — самопроверка
агента по тексту `intent.md`, с явной пометкой, что это не подтверждение человека:

- Необходимое (агент): да — «Что делаем» построчно совпадает с `task.md` и двумя ответами
  интервью (ставка 90%, зона far), расширений сверх заданного нет
- Единичное (агент): да, с одной правкой по ходу самопроверки — claim-1 и claim-5 изначально
  использовали одни и те же габариты `[120,100,80]` (дублирование сценария под двумя id);
  claim-1 переведён на обычный случай в пределах габаритов (`order()`, `[20,15,10]`), claim-5
  оставлен как граничный случай `[edge]`
- Однозначное (агент): да — во всех пунктах числовые входы и ожидаемые числа названы явно
- Проверяемое (агент): да — каждый пункт называет конкретный вызов `priceFor(...)` и
  конкретное ожидаемое значение или структуру объекта

**Примеры пересчитаны:** вручную, по формулам из `src/money.ts` (`percent(amount, pct) =
floor(amount·pct/100 + 0.5)`) и `src/tariffs.ts` (`basePrice`, `subtract`), без запуска
интерпретатора — на этапе 1 нет инструмента для исполнения кода. Проверено:
- claim-2: `percent(24900,40)=9960`, `total=24900+9960=34860` ✓
- claim-3: `percent(24900,90)=22410`, `total=24900+22410=47310` ✓
- claim-4: та же ставка 90% (условия совпали, берётся бо́льшая) → те же числа, что claim-3 ✓
- claim-6: `discount=percent(24900,12)=2988` (совпадает со значением в существующем тесте
  `test/tariffs.test.ts` для gold-клиента без надбавки — база и скидка от неё не меняются),
  `surcharge=9960`, `total=24900-2988+9960=31872` ✓
- claim-7: `base(far,300г)=48925` (как в существующем тесте «дальняя зона берёт свой тариф»),
  `percent(48925,40)=19570`, `total=48925+19570=68495` ✓
- claim-1, claim-5: `total=24900` (база msk/900г без скидки — то же значение, что в
  существующем тесте «разовое отправление считается по базе без скидки») ✓

Ручной пересчёт будет продублирован исполнением тестов на этапе 6 (claim-9) — если арифметика
здесь разойдётся с прогоном, разойдётся и тест, и это будет видно по красному гейту, а не
пропущено молча.
