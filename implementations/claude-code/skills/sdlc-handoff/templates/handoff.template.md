> Следующий виток той же задачи дописывает новую секцию с новой шапкой, не переписывает эту.
> `SDLC.md` → этап 7.

- **Задача:** ‹id или название — то же на всех витках этой задачи›
- **Предыдущая передача по этой задаче:** ‹ссылка или файл› / нет — это первый виток
- **Приёмка:** принял ‹имя› · ‹дата› / **не принималась — обрыв: ‹почему›**

## Готовность

_Статусы переносятся из отчёта приёмки **как есть, включая `⏭`**: это источник наблюдения «какой
гейт не работает», и подмена на `✅` его стирает._

- Пункты в `❌`: ‹id› / ни один · Пункты в `⚠`: ‹id› / ни один / н/п — приёмка не запускалась
- **Пункты `[manual]` — открытая ручная проверка** (не проверялись этим этапом по построению,
  не роняли `passed`): ‹id — что именно проверить и как› / ни одного

| Гейт | Статус |
|---|---|
| ‹гейт› | ‹✅/❌/⏭› |

_По каждой включённой строке набора — одна строка таблицы. Приёмка не запускалась — таблица удаляется целиком, остаётся единственная строка «н/п — приёмка не запускалась»._

- Закрыто вручную вместо гейта из долга: ‹ссылка на строку «Долга» в наборе› / н/п

## Наблюдения витка

_Наблюдения, **не цели и не квоты**. Только то, что не выводится из таблиц выше: возвраты — из
журнала chunk'а, дефекты — из блоков ниже; статусы гейтов уже стоят в «Готовности», их сюда
не переписывают._

- Возвратов на этом chunk'е: ‹K−1 из журнала chunk'а› _(0 = приёмка с первой попытки)_
- Пункты, закрытые не тестом, а diff'ом: ‹id› / ни один
- Записи о дефектах на этом витке: ‹имена из блоков ниже› / ни одной

## Запись о проскочившем дефекте

_Заполняется, если дефект прошёл гейты и найден позже — на приёмке, в проде, следующим витком, —
либо если ревью нашло поведение, не покрытое ни одним пунктом приёмки. Кандидатов собирать по
**всем** отчётам приёмки витка, не только последнему. **Одна запись на один дефект:** нашлось
несколько — блок повторяется._

_Дефектов не было — оставить один блок со «нет» в поле «Имя» и `н/п` в остальных. Это единственный
случай, когда `н/п` допустим в «Действии» и «Кто утвердил». **В записи о реальном дефекте все поля
обязательны:** без действия и без имени утвердившего запись значит то же, что её отсутствие._
