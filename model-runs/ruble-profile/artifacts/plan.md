### Подход
Реализуем надбавку за негабаритные посылки через расширение функции `priceFor` в `src/tariffs.ts`. Логика негабаритности выносится в отдельный модуль в директории `src/`, чтобы избежать загромождения основного файла. Используем найденные функции `longestSide` и `dimensionSum` для проверки условий негабаритности.

---

### Шаги
1. **Использовать `src/tariffs.ts:longestSide`** для проверки негабаритности по наибольшей стороне.
2. **Использовать `src/tariffs.ts:dimensionSum`** для проверки негабаритности по сумме измерений.
3. **Добавить логику в `priceFor`** для расчета надбавки `surcharge`:
   - Если сумма измерений > 300 см, надбавка = 50% от базовой цены зоны.
   - Иначе (если наибольшая сторона превышает порог), надбавка = 40% от базовой цены зоны.
4. **Добавить поле `surcharge`** в объект `Quote` для негабаритных отправлений.
5. **Убедиться, что `total` учитывает `surcharge`** для негабаритных отправлений.
6. **Создать отдельный модуль** для логики негабаритности (например, `src/oversize.ts`).
7. **Добавить тесты** для проверки нового поведения в `test/`.
