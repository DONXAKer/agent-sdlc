## Вопросы и ответы
_Только то, без чего нельзя начать, и только то, что нельзя добыть из кода: факт, который добывается
чтением кодовой базы, агент добывает сам. Один вопрос = одна неопределённость. Нет ответа →
«(пропущено)», работа не блокируется. Пропущен **блокирующий** → эскалация, не старт._

## Уточнённое требование и подход
_Точная переформулировка с учётом ответов: сохраняет исходное намерение, не переинтерпретирует.
Плюс согласованный подход одной-двумя фразами. Идёт входом в план._
